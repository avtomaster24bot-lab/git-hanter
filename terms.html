Условия использования Git Hunter

Материалы сайта (обзоры, аудио и видео) созданы автоматически и носят ознакомительный характер. Они могут содержать неточности, поэтому перед использованием проекта проверяйте детали в его README и лицензии.

Права на проекты принадлежат их авторам. Git Hunter только рассказывает о них и ставит ссылку на оригинал.

Приложение Git Hunter использует API соцсетей только для публикации видео в аккаунты владельца этого проекта.
