# 🔎 Git Hanter

**Сайт, который каждый день находит интересные проекты на GitHub и объясняет их простыми словами.**

🌐 Сайт: https://avtomaster24bot-lab.github.io/git-hanter/
📰 RSS: https://avtomaster24bot-lab.github.io/git-hanter/feed.xml

## Что умеет

- **Подборка дня** — каждое утро в 08:00 (Алматы) 8–10 свежих и быстрорастущих проектов.
- **Понятный разбор на русском** для каждого проекта: что это, зачем нужен, что умеет, кому пригодится, как начать, сложность.
- **Картинка** — превью репозитория + первая картинка из README.
- **Аудио-рассказ** на 30–60 секунд (бесплатный синтез речи `edge-tts`, голос Светланы). Можно слушать всю подборку подряд, как подкаст.
- **Поиск**: по всем прошлым подборкам и **по всему GitHub** прямо из браузера (популярные или свежие за 90 дней).
- **Фильтры** по категориям и языкам программирования.
- **🔥 Тренд недели** — репозитории, которые быстрее всех набирают звёзды за последние 7 дней.
- **★ Избранное** — сохраняется в браузере.
- **Архив** по дням и **RSS-лента**.
- **Telegram** — подборка с картинками и аудио может приходить в ваш чат (см. ниже).
- Проекты **не повторяются**: уже показанные исключаются.

## Как это работает

```
GitHub Actions (каждый день 03:00 UTC)
 └─ scripts/generate.py
     ├─ GitHub Search API: свежие репозитории по темам из topics.json
     ├─ рейтинг: звёзды в день, разнообразие категорий, без повторов
     ├─ README → GitHub Models (gpt-4o-mini) → разбор на русском (JSON)
     │    └─ если ИИ недоступен — шаблон из описания репозитория
     ├─ edge-tts → audio/*.mp3 (запасной вариант — gTTS)
     └─ data/ДАТА.json, data/index.json, data/projects.json, data/trend.json, feed.xml
 ├─ коммит в репозиторий
 ├─ scripts/telegram.py (если заданы секреты)
 └─ деплой сайта на GitHub Pages
```

Сайт — обычные `index.html`, `app.js`, `style.css`, без сборки.

## Настройка тем

Откройте `topics.json`:

- `categories` — встроенные категории (ИИ, инструменты разработчика, автоматизация, боты, веб, self-hosted, мобильные, медиа, безопасность). У каждой — список поисковых запросов GitHub (`topic:llm` и т.п.).
- `user_topics` — **ваши темы**: любое имя и поисковый запрос, например
  `{"name": "Авто и автосервис", "emoji": "🚗", "query": "car OR automotive OR obd2"}`.
- `per_day` — сколько проектов в подборке, `max_per_category` — не больше N из одной категории,
  `fresh_days` — насколько свежими должны быть проекты, `min_stars` — минимум звёзд,
  `voice` — голос (`ru-RU-SvetlanaNeural` или `ru-RU-DmitryNeural`), `model` — модель GitHub Models.

## Запуск вручную

Actions → **Ежедневная подборка** → **Run workflow** (галочка «Пересобрать подборку за сегодня» — собрать заново).

Локально:
```bash
pip install -r requirements.txt
GITHUB_TOKEN=ваш_токен python scripts/generate.py
python -m http.server 8000   # и откройте http://localhost:8000
```

## Доставка в Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Напишите своему боту любое сообщение (или добавьте его в канал/группу администратором).
3. Узнайте chat id: откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": ...}`
   (для канала можно использовать `@имя_канала`).
4. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**:
   - `TELEGRAM_BOT_TOKEN` — токен бота
   - `TELEGRAM_CHAT_ID` — id чата
5. Готово: со следующего запуска подборка будет приходить в Telegram — заголовок, затем для каждого проекта картинка с описанием и аудио-рассказ.

Без этих секретов шаг Telegram просто пропускается.
