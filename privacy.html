Политика конфиденциальности Git Hunter

Git Hunter — некоммерческий проект, который публикует обзоры открытых проектов GitHub на этом сайте и в аккаунтах автора в YouTube, Instagram, TikTok и Telegram.

Сайт не собирает персональные данные посетителей: не использует cookies и аналитику. «Избранное» хранится только в вашем браузере (localStorage). Поиск по GitHub выполняется вашим браузером напрямую через публичный API GitHub.

Токены доступа к соцсетям используются только для публикации видео в аккаунты автора проекта. Они хранятся в зашифрованных секретах GitHub Actions и никому не передаются.

Вопросы: через Issues репозитория github.com/avtomaster24bot-lab/git-hunter.
